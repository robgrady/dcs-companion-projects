Saved Games extraction planner

Leave no binding behind.

Build a precise, reviewable PowerShell runbook for backing up DCS controls, settings, missions, logbook data, liveries, scripts, and other user-owned files before an update, reinstall, or PC move.

Define the move

Set the source, destination, and reason. Config Evac never reads your filesystem; it produces commands for you to review and run on the Windows PC that hosts DCS.

STEP 01 / 04
Current releases commonly use DCS; older installs may retain DCS.openbeta.
Local drive, external drive, or synced folder. A dated subfolder is created automatically.
Before running anything: close DCS, the DCS launcher, VoiceAttack, SRS, and utilities that may write into Saved Games. Read the generated script before execution.

Choose the payload

Start broad, then trim only what you knowingly do not need. Cache folders are deliberately excluded because DCS can rebuild them.

STEP 02 / 04
Not included: the DCS installation directory, purchased modules, fxo, metashaders2, logs, and crash dumps. This app protects user-owned state under Saved Games; it is not an installation clone.

Run the extraction

Copy the script into PowerShell on the DCS PC, or download it as a .ps1 file. It creates a dated folder, copies only selected payloads, and writes SHA-256 inventory files.
