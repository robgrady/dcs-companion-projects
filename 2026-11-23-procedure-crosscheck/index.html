How the crosscheck works

1. Name the evidence

Record where each procedure came from and its date or version. A newer source is not automatically a better source.

2. Align the wording

The app compares normalized action words and order. Green means similar language, amber means a possible match, and blue marks a step present in only one source.

3. Make the call

Choose A, B, merge the wording, or skip each row. Verify disputed steps in the current module manual, official change log, or a controlled cockpit test.

4. Preserve provenance

Export the project before a module update. Re-run the crosscheck when a patch changes cockpit behavior.

Limits

  • Text similarity is not procedural correctness.
  • The app does not know airframe limitations.
  • Do not use this artifact for real-world aviation.
