Planning aid only. Target Weave does not control DCS, parse a mission file, or guarantee AI behavior. Task availability and execution can vary by aircraft, role, target, weapon, geometry, mission construction, and DCS version; verify each build with short controlled tests.

Build a deliberate strike allocation

  1. Define flights. Give each AI group a recognizable callsign, role, and realistic maximum number of target tasks.
  2. Define targets. Copy the exact Mission Editor target name and select the task family you intend to test.
  3. Weave assignments. Give every required target one primary shooter. Add a reserve only when the mission has a clear trigger or decision point for using it.
  4. Resolve warnings. Duplicate primaries, overloaded flights, and required targets without shooters are visible before you build.
  5. Test one layer at a time. Use the generated cards as a build checklist, then run a short track and record the outcome before adding complexity.

The app is intentionally evidence-minded: it organizes intent and test results without pretending DCS AI will always execute a valid-looking task.
