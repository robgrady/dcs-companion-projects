Method & keyboard controls
  1. Define observable events before flying. Prefer externally visible, unambiguous moments.
  2. Run the original sortie. Start the timer at a repeatable reference, then press M at each event.
  3. Switch to Replay pass, zero the timer at the same reference, and mark the same events.
  4. Set each assessment to Match, Diverged, or Not observed. Track Witness identifies the earliest break and timing drift.

Controls: Space start/pause · M mark next · R zero timer. Keyboard shortcuts are disabled while typing in fields.
