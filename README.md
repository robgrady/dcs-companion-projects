# DCS Companion Projects

A growing collection of self-contained, offline companion web apps for Digital Combat Simulator (DCS World). Each dated folder contains one complete project that runs directly from its `index.html` file without a build step or internet connection.

See [INDEX.md](INDEX.md) for the complete project catalog.

## Using a project

1. Open a dated project folder.
2. Download the folder or clone this repository.
3. Open that project's `index.html` in a modern browser.
4. Read its `README.md` for project-specific guidance and community research sources.

Projects are generated as focused, single-session builds and verified before publication.
