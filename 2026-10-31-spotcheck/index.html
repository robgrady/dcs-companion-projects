A/B protocol

ONE VARIABLE

Make “I can’t see contacts” measurable.

Spotcheck is a controlled browser drill, not a model of DCS World’s spotting renderer. Its job is to keep the visual task stable while you compare your own attention, display posture, and setting profiles.

Recommended loop

  1. Save the current DCS and display state as Profile A.
  2. Run the same 10- or 20-trial contract twice.
  3. Change exactly one variable in DCS or the display stack.
  4. Create Profile B, repeat the identical contract, and compare contact rate plus median acquisition time.
  5. Confirm any apparent improvement in an actual DCS test mission before keeping it.
Do not infer realism from a better score. A result only says that a browser mark was easier to acquire under that profile and test posture.

Field notes

Community reports about DCS visual spotting vary sharply by monitor resolution, VR headset, pixel density, anti-aliasing or upscaling choice, multiplayer server policy, background clutter, and mission conditions. Spotcheck gives one player a repeatable baseline without claiming to settle those rendering debates.

Keyboard

Space records contact during a live exposure. M records a miss. Esc ends a run. Alt + 1–4 switches views.

Privacy and offline use

No network requests, accounts, analytics, remote fonts, or external libraries are used. Profiles and run evidence remain in this browser’s local storage unless you export a backup.

Limits

CSS pixels, browser scaling, VR browser behavior, and display processing differ from DCS’s renderer. The generated marks do not represent a particular aircraft, angular size, range, lighting model, LOD transition, dot implementation, or server setting. This is simulation-only attention and comparison tooling.
